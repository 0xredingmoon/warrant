The contract is the policy

Limits are checked inside the payment transaction. A compromised or prompt-injected agent can only ask; the vault answers with a reason it can read back.

The agent never needs gas

It signs an EIP-712 intent. A relayer submits it and pays the fee, so the agent key holds no funds and cannot be drained.

Merchants verify from chain data

A merchant serves a request after reading the payment event from the vault. Paid invoices build a receipt-bound reputation for the agent.
